# Alice Friseur Team – statischer Verkaufsprototyp

index.html direkt im Browser öffnen. Kein Build, kein Framework, keine Installation notwendig. Alle Bilder liegen lokal unter assets/. Die einzigen externen Links sind die Routenplanung und die Quellen in dieser Dokumentation.

## Cloudflare Pages (spätere Veröffentlichung)
- Framework: None
- Build command: exit 0
- Build output directory: .

## Inhalte bearbeiten
- Startseite: index.html
- Leistungen und Preise: leistungen.html; nach PREISPLATZHALTER oder ab XX € suchen.
- Gestaltung: style.css
- Mobiles Menü: script.js

Alle zehn Preise sind ausdrücklich gekennzeichnete Platzhalter. Terminlinks starten einen Telefonanruf. Es gibt kein Buchungssystem und kein Kontaktformular. Vor einer öffentlichen Verwendung sind die tatsächlichen Preise sowie die benötigten Betreiber- und Datenschutzangaben vom Salon zu ergänzen. Es wurden keine unbekannten Betreiberangaben erfunden.
